# kodaris-updates

Подписанные обновления программы «Кодарис».

## Установщики macOS 1.0.30

Workflow `macOS installers 1.0.30` запускается вручную или при отправке изменений
в его файлы на ветку `main`. Он упаковывает опубликованный выпуск `v1.0.30`
на стандартных GitHub macOS runners для Intel и Apple Silicon.
Исходники программы и закрытые ключи подписи для сборки не требуются.

Хеши пакета обновления и библиотек JavaFX закреплены в `packaging/*.sha256`.
Перед загрузкой проверяются версия DMG и встроенные проверки программы:
уведомления, щелчок по уведомлению, окно JavaFX и подпись лицензии.

Результаты добавляются к существующему выпуску `v1.0.30`:

- `Kodaris-1.0.30-apple-silicon.dmg` и его `.sha256`;
- `Kodaris-1.0.30-intel.dmg` и его `.sha256`.

Workflow не использует Actions artifacts или кеш и не заменяет уже загруженные
файлы выпуска. Если имя занято, повторная загрузка завершается ошибкой.
Подпись Developer ID и нотариальное заверение Apple в этот сценарий не входят.
